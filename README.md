# Next Level Assignment 1 — TypeScript & OOP

This repository contains my TypeScript assignment covering problem-solving concepts from Modules 1, 2, and 3, along with two technical blog posts.

## Problem-Solving Solutions

The [`solutions.ts`](./solutions.ts) file contains eight solutions covering:

- Basic types, optional parameters, and default values
- Union types and type narrowing
- Readonly tuples
- Generics and rest parameters
- Interfaces and array filtering
- `keyof` constraints and indexed access types
- Object-oriented programming, inheritance, and access modifiers
- Asynchronous programming with Promises

## Blog Posts

**1. [Type Aliases vs Interfaces in TypeScript](./type-vs-interface.md)**

Explains the differences between `type` aliases and `interface`, how they extend or combine types, and when to use each.

**2. [Type Narrowing in TypeScript](./TypeNarrowing.md)**

Explains how TypeScript narrows types using `typeof`, `instanceof`, and the `in` operator, with practical examples.
